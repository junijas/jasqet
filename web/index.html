Jasqet
Free and open source (MIT licence). No ads, no bundled software, no tracking: it never sends anything about you anywhere. The full source code comes with it, so anyone can check what it does.
What it talks to: the sites you download from; GitHub, to set up and update the YouTube helper tools (only if you use YouTube); GitHub and Hugging Face, to set up automatic subtitles the first time you make them (the listening itself happens on this computer); VirusTotal and Telegram only if you set them up.

Watch rules

Jasqet keeps an eye on these and downloads what's new, either straight away or at your scheduled time when data is cheaper. Paste a YouTube channel or playlist, a podcast feed, a GitHub project (for new releases) or any web page (for new files on it).

Connect your browser

Browsers don't let programs install extensions by themselves, so this takes a minute, once:
  1. Click your browser below. It opens, and the address of its extensions page is copied: click the address bar, press Ctrl+V and Enter.
  2. Turn on Developer mode (a switch at the top right in Chrome and Edge).
  3. Click Load unpacked and choose Jasqet's extension folder: and paste it into the address bar at the top of the folder window (it's in a hidden folder, so clicking through won't find it), or .
  4. Pin the blue Jasqet icon. That's it. This window says Connected when it works.
Firefox: open about:debugging → This Firefox → Load Temporary Add-on → pick manifest.json in the Firefox extension folder (). See the README to keep it permanently.
